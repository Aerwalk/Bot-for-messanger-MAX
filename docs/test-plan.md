# Тест-план MVP «Спорт рядом»

Охват: мини-приложение (UX-состояния), бот, админ-панель и backend (API). Тесты backend выполняются
автоматически (pytest, 40 кейсов); UX-сценарии проверяются вручную по чек-листу.

## 1. Автоматические тесты backend (pytest)

Запуск: `npm run test:backend` или `.venv\Scripts\python.exe -m pytest backend/tests -v`.

## 2. Чек-лист сценариев мини-приложения (ручной)

### Happy path
- [ ] Бот `/start` → приветствие + меню (Поиск / Популярное / Мои записи / Избранное / Профиль / Помощь).
- [ ] Мини-приложение открывается, сессия создаётся через `POST /api/me`.
- [ ] Выбраны вид спорта → день → время → поиск.
- [ ] Результаты показывают карточки с типом, адресом, ценой, возрастом, доступностью, оценкой занятия и рейтингом тренера.
- [ ] Открыта карточка: описание, расписание, свободные места, источник данных.
- [ ] Выбран открытый слот → заполнена форма (имя + согласие).
- [ ] Показано подтверждение записи; после записи бот предлагает «Построить маршрут».
- [ ] Запись есть в «Моих записях»; её можно отменить.
- [ ] После отмены слот снова доступен.

### Оценка после занятия
- [ ] Прошедшее занятие в «Моих записях» открывает форму оценки (тренировка 1–5, тренер 1–5, комментарий).
- [ ] Повторная оценка того же слота блокируется (unique userId+slotId).
- [ ] Оценка и рейтинг тренера появляются в карточке активности и у бота.

### Empty
- [ ] Поиск с заведомо несовместимыми фильтрами → «Ничего не найдено».
- [ ] Предложены действия: изменить время/радиус/показать все.

### Full
- [ ] На заполненном слоте (плавание, день+1, 19:00) кнопка «Записаться» недоступна.
- [ ] Регистрация на него с сервера → 409 SLOT_FULL (показана ошибка).

### Duplicate
- [ ] Повторная запись на тот же слот → 409 DUPLICATE, понятное сообщение.

### Validation
- [ ] Пустое имя → ошибка поля.
- [ ] Некорректный телефон → ошибка поля.
- [ ] Снято согласие → ошибка поля, запись не уходит.

### Network error / Retry
- [ ] Бэкенд остановлен → экран ошибки загрузки.
- [ ] Кнопка «Повторить» повторяет запрос после поднятия бэкенда.

### Cancellation
- [ ] Отмена записи подтверждается; статус меняется на отменённую.

### Reopen
- [ ] Закрытие и повторное открытие мини-приложения не ломает сценарий.
- [ ] Повторный поиск работает, старые записи сохранены.

## 3. Чек-лист бота (ручной)

- [ ] Кнопка геолокации («📍 Указать геолокацию») — только в профиле, не на первом экране.
- [ ] После указания гео поиск идёт от координат пользователя (иначе центр Москвы).
- [ ] В результатах и карточках показаны тренер и его рейтинг, оценка занятия.
- [ ] На подтверждении записи и после неё — кнопка «🚶 Построить маршрут» (Яндекс Карты).
- [ ] Напоминание приходит за 3 часа (требует `MAX_BOT_TOKEN` и реального бота MAX).
- [ ] «Мои записи» показывает status, время и место; отмена работает.
