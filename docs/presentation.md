# Структура презентации проекта «Спорт рядом»

Целевые лимиты: проблема — за 30 секунд, ценность — за 1–2 минуты, сценарий без тупиков —
полное прохождение демо.

| 14 | **Масштабирование** | ядро (проблема, UX, модель данных, API) vs переменная часть (город, справочники, источники); путь пилот → район → город → регион | конкретная логика, не «на всю Россию» |
| 15 | **Ограничения и риски** | демо-данные; нет оплаты; гео требует HTTPS при публикации; админка — демо-организатор; напоминания требуют зафиксированного чата; публикация в MAX требует токена | честно |
| 16 | **Итог** | главное: пользователь в MAX находит вариант, выбирает занятие и получает подтверждённую запись; что дальше (пилот, официальные данные) | CTA / следующий шаг |

## Правила слайдов

- Не перегружать второстепенной информацией.
- Каждый ключевой продуктовый выбор объясняется одной фразой.
- Демо-шаги — из `README.md` («Пошаговый сценарий проверки»).
- Факты, гипотезы и ограничения разделяются явно (например, «подтверждено / предположение / ограничение»).
